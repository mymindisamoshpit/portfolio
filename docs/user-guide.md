# Руководство пользователя (Выжимка)

## Описание операций
1. **Настройка подключения:** Параметры задаются в `config.json`. Поддерживаются COM-порт (`connection_type = "0"`) и TCP/IP (`connection_type = "6"`).
2. **Открытие смены:** Смена открывается автоматически при пробитии первого чека (метод `OpenShift` используется для явного вызова).
3. **Пробитие чека:** Формирование данных и вызов метода `ProcessCheck`. Проверка кода результата (0 – успех).
4. **Закрытие смены:** Вызов метода `CloseShift`. Печатается Z-отчет, смена закрывается.
5. **Проверка состояния:** Метод `CheckFRState` проверяет наличие бумаги, режим работы и статус смены перед любой операцией.

## Архитектура драйвера
Драйвер состоит из трех модулей:
- `ufr.pas` (Класс `Tfr`) — публичный интерфейс для кассового ПО.
- `DrvFRLib_TLB.pas` — библиотека типов для низкоуровневого COM-взаимодействия с ФР.
- `udm.pas` — работа с конфигурацией (JSON) и базой данных (PostgreSQL).

## Возможные ошибки и способы их устранения
| Код | Описание | Способ устранения |
|---|---|---|
| 0 | Успешное выполнение операции | - |
| 1 | Отсутствие связи с ФР | Проверить кабель, питание, параметры в `config.json` |
| 2 | Отсутствие бумаги | Заправить бумагу в фискальный регистратор |
| 3 | Смена не открыта | Вызвать метод `OpenShift` |
| 4 | Смена уже закрыта | Открыть новую смену |
| 5 | Ошибка фискального накопителя | Обратиться к администратору |
