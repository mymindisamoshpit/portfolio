# Портфолио: анализ, моделирование, техническая документация

Учебные и практические работы по специальности 09.02.07 «Информационные системы и программирование».
Основной кейс: драйвер фискального регистратора Штрих-М (преддипломная практика и ВКР).

> Данные организации, в которой проходила практика, обезличены.

## Навигация

- Диаграммы (UML Use Case, Class, IDEF0, архитектура, Гант, блок-схемы): папка `diagrams/`
- Техническое задание, выжимка по ГОСТ 19.201-78: `docs/spec.md`
- Тест-кейсы, 4 кейса со шагами и статусами: `docs/test-cases.md`
- Руководство пользователя, выжимка и таблица ошибок: `docs/user-guide.md`
- Фрагменты кода на Delphi и пример конфигурации: папка `code-samples/`
- Исходники диаграмм и плана-графика (Visio, MS Project): папка `sources/`

## Основной кейс: драйвер фискального регистратора

Цель: программный компонент на Delphi для связи кассового ПО с фискальным регистратором Штрих-М в соответствии с 54-ФЗ, с подключением через COM-порт и TCP/IP.

Стек и инструменты: Object Pascal (RAD Studio Delphi), COM-объекты, PostgreSQL, JSON, MS Visio (UML, IDEF0), MS Project.

## Роль в проекте и авторство

Исходный код драйвера был предоставлен организацией как уже существующее решение.
Моей задачей был анализ этого решения и построение вокруг него моделей, тестов и документации.

Что я сделал лично:
- Анализ предоставленного исходного кода (Object Pascal, COM-объект TDrvFR): архитектура трех модулей, логика методов, взаимодействие с PostgreSQL и config.json
- Моделирование по результатам анализа: диаграммы UML (вариантов использования, классов), IDEF0 (контекстная и декомпозиция), схема архитектуры драйвера
- Тестирование: разработал 4 тест-кейса и выполнил их на стенде (открытие и закрытие смены, печать чека, обработка потери связи)
- Техническая документация: описание операций, таблица кодов ошибок и способов устранения; текст руководства пользователя подготовлен с помощью ИИ-ассистента по моей структуре и техническим референсам, результат я проверял и редактировал
- Планирование работ: календарный план практики в MS Project (диаграмма Ганта)

Фрагменты кода в папке `code-samples/` приведены как иллюстрация проанализированной архитектуры, а не как моя собственная разработка.
